# 📓 Interactive Jupyter Notebooks

This directory contains interactive, hands-on Jupyter Notebooks (`.ipynb`) covering core Python concepts and coding interview problem patterns.

Each notebook includes:
- 📖 **Clear Explanations & Theory**: Mental models, diagrams, and algorithmic intuition.
- ⏱️ **Complexity Analysis**: Big-O Time and Space complexities.
- 💻 **Interactive Code Cells**: Clean implementations ready to execute and modify.
- 🧪 **Built-in Assertions & Tests**: Validate edge cases immediately.
- 🚀 **1-Click Google Colab Support**: Run directly in your browser without any local setup.

## 🚀 How to Run Locally

### Option 1: Visual Studio Code (Recommended)
1. Install the **Python** and **Jupyter** extensions in VS Code.
2. Open any `.ipynb` file directly from this folder.
3. Select your Python interpreter (Python 3.10+) in the top-right corner.
4. Click **Run All** or press `Shift + Enter` to execute cells.

### Option 2: JupyterLab / Jupyter Notebook
```bash
# Install Jupyter if not already installed
pip install jupyterlab notebook

# Launch JupyterLab from the project root
jupyter lab
```
